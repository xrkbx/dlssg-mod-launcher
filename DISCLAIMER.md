## Antivirus notice

The DLSS Frame Generation mod uses a system-DLL proxy and API hooks to integrate with games. This behavior may trigger heuristic antivirus false positives. This is a known characteristic of this class of mod. The launcher includes an optional helper to add a Windows Defender exclusion for a game folder you trust. Only exclude folders you understand and trust, and always obtain the mod and DLLs from their official sources.
